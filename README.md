# Recomp-Plan Spanien 🍽️

Persönlicher Ernährungs- / Recomp-Plan als kleine Web-App.

## Auf dem iPhone als App speichern
1. Die GitHub-Pages-Adresse in **Safari** öffnen.
2. Auf das **Teilen-Symbol** (Quadrat mit Pfeil nach oben) tippen.
3. **"Zum Home-Bildschirm"** wählen → fertig. Die App liegt jetzt als Icon auf dem Home-Bildschirm.

Öffnet sich im Vollbild wie eine normale App.
